**The stem model's licence.** Demucs's code is MIT, but its author writes that the licence of its trained weights "is not clear", and that the six-stem model EarBee uses "was trained only on Meta internal dataset, which likely means CC-NC-BY license is applicable, as it was the case for all models released by FAIR" (Demucs's README, "License"). So the model is treated as free for non-commercial use, with credit to Demucs and Meta. It isn't part of EarBee and isn't covered by EarBee's MIT licence: it's a separate download, from [EarBee/models](https://github.com/EarBee/models), whose README says the same.

The full licence texts of the npm packages are in each package's folder under `node_modules/` (and inside the app's `resources/app.asar` in a release).
